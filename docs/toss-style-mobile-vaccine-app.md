# 모바일 백신 앱 토스 스타일 UI 시안

이 문서는 모바일 백신 앱의 주요 여정을 토스 디자인 시스템에서 공개적으로 확인 가능한 톤으로 재정리한 이미지 시안의 설명서예요.

## 산출물

- 이미지 시안: [`toss-style-mobile-vaccine-app.svg`](./toss-style-mobile-vaccine-app.svg)
- 포함 화면: 로그인, 회원가입, 휴대전화 인증, 환영, 메인, 검사 상세, 권한 관리, 보안 리포트

## 적용한 UI/UX 방향

- 흰 배경과 밝은 회색 섹션으로 화면을 가볍게 나눴어요.
- 핵심 CTA는 토스 계열의 밝은 파란색 `#3182F6`을 사용했어요.
- 문장은 “검사했어요”, “정리해요”, “안전해요”처럼 짧고 부드러운 한국어로 썼어요.
- 각 화면은 하나의 다음 행동만 강하게 보이도록 구성했어요.
- 카드와 입력 필드는 넉넉한 라운드와 여백을 사용해 모바일 터치 흐름을 단순하게 만들었어요.
- 토스의 비공개 브랜드 폰트나 실제 앱 화면 자산은 복제하지 않고, 시스템 폰트와 공개적으로 확인 가능한 색상·간격 톤만 참고했어요.

## 화면별 개선 포인트

1. **로그인**: 보안 앱의 첫인상을 “기기를 매일 안전하게 지켜요”로 단순화하고, 로그인 CTA를 하단에 고정된 주요 행동처럼 배치했어요.
2. **회원가입**: 입력 항목을 최소화하고 약관 동의를 한 줄 카드로 정리했어요.
3. **휴대전화 인증**: 6자리 인증번호 입력에 집중하도록 다른 요소를 줄였어요.
4. **환영**: 가입 완료 후 곧바로 첫 검사를 시작하도록 추천 카드를 넣었어요.
5. **메인**: 위협 수, 실시간 보호, 개인정보 상태를 한눈에 볼 수 있게 카드화했어요.
6. **검사 상세**: “안전” 상태를 먼저 보여준 뒤 세부 검사 항목을 아래에 배치했어요.
7. **권한 관리**: 민감 권한을 부드러운 경고 카드로 표현하고, 정리 행동을 명확히 만들었어요.
8. **보안 리포트**: 점수와 개선 내역을 짧게 보여줘 재방문 동기를 만들었어요.
